TL;DR: I implemented the ABD-Net dynamics prior as a trainable DGL policy, validated it with PPO, and reused its link representations to condition a diffusion policy trained from robot demonstrations.

Abstract

Neural robot policies often learn the physical relationships between links and joints only through task data. ABD-Net introduces a stronger architectural prior by adapting the computational structure of the Articulated Body Algorithm. Link representations propagate from child bodies toward their parents, reflecting how inertial effects accumulate through an articulated system.

This project independently implements ABD-Net in PyTorch and DGL, constructs its kinematic graph directly from a SAPIEN articulation, and integrates the resulting actor with PPO in ManiSkill. The implementation includes per-link observation encoders, bottom-up dynamics-informed message passing, per-joint action decoding, and the weighted orthogonality regularizer proposed in the paper.

The project then extends ABD-Net beyond reinforcement learning. Its encoder and message-passing modules provide structural observation conditioning for a state-based diffusion policy. Root-conditioned and all-node variants are evaluated against the official diffusion-policy baseline on RollBall.

From Paper to Experiment

The project was developed in four stages.

01 · PAPER

02 · IMPLEMENT

03 · VALIDATE

Method Overview

ABD-Net defines not only where information travels, but also a dynamics-inspired rule for how it is transformed.

Φ

Link-wise encoding

Each robot link independently maps the full observation into its own link-specific feature representation.

M

Dynamics message passing

Features propagate from leaf links toward the root using learnable inertia offsets and motion bases.

Ψ

Joint-wise action decoding

Each joint action is decoded from its parent link’s propagated representation.

total_loss = diffusion_loss + 10⁻⁴ × orthogonality_loss

Implementation Details

The robot articulation is extracted from SAPIEN once at startup. Controlled joints determine the included links, and every graph edge points from child to parent. Actuator indices are stored independently so graph traversal order cannot be confused with the action order required by env.step(action).

DGL performs batched topological propagation over the kinematic trees. Each link begins with a positive local representation, accumulates messages from its children, and transmits an attenuated contribution toward its parent.

The message function uses a smooth bounded projection to prevent quadratic amplification through deeper trees while retaining differentiability.

Extension to Imitation Learning

The diffusion extension retains the official ManiSkill state-based pipeline. The link-wise encoder and message-passing modules transform observations into structural robot features, which are concatenated with the unchanged normalized state before conditioning the diffusion model.

Root-conditioned ABD

Uses the propagated root representation as a compact summary of the complete child-to-parent kinematic chain.

All-node ABD

Retains all eight propagated Panda arm features, directly or through a learned projection.

Qualitative Results

Official diffusion policy with action horizon 12.

Competitive structural prior

Root-conditioned ABD ties the baseline at horizon 8 and achieves a four-point higher peak at horizon 15.

Configuration matters

The baseline retains the highest peak at horizon 12, so ABD is not consistently better.

Compression matters

Supplying all 2,048 features directly performs worse than compact or projected conditions.

Limitation: Success-at-end is low for every evaluated policy.
